# 🌤️ Skyline Weather App

A modern and responsive **Skyline Weather Application** that provides real-time weather information, hourly forecasts, and a 7-day weather outlook for locations around the world.

The application uses the **Open-Meteo API** for weather data, **Leaflet.js** for interactive map location selection, and is built using **HTML, CSS, and JavaScript**. No API key is required.

## 🌐 Live Demo

**Weather App**  

https://madhan-03.github.io/skyline-weather/

## 📖 Project Overview

Checking weather information from multiple sources can be inconvenient. This application provides a simple and centralized interface for viewing current weather conditions, hourly forecasts, and upcoming 7-day weather data.

Users can search for a city, use their current location, or select any location directly from the interactive map.
